# Palaver

Palaver is a local-first, modular personal dashboard for daily puzzles, news, and more. The first planned feature is a puzzle dashboard for finding daily games, recording results, and reviewing history and statistics.

The repository is in the foundation stage. The planned app uses a Rust backend with Axum and Tokio, a React and TypeScript frontend, and a local SQLite database. The initial target is a native Windows process accessed from a browser on the same machine. Application setup and run commands will land with the backend and frontend bootstraps.
